Ethiopian Crop Yield Prediction App

An agricultural machine learning application developed for the Qiyas Hackathon 2026. It uses agricultural and regional weather data to predict crop yields across Ethiopia, supporting data-driven agricultural planning and decision-making.

My Contribution: Data engineering, data preprocessing, feature engineering, weather-data integration, and machine learning development.

Dataset: 15,090 training observations covering five Ethiopian regions and five major crops.

Technologies: Python, Pandas, NumPy, Scikit-learn, Machine Learning, Streamlit.
